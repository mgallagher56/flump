# Mutation triage ledger

This is the one place where faults that no test catches are recorded (E41 decision 2, option B). Stryker never reads this file. Every fault listed here still counts against the score, so the floor in `scripts/mutation-baseline.json` sits below 100 to allow for them. Nothing is suppressed. How the runs work is in [mutation-testing.md](./mutation-testing.md).

## Classes

| Class             | Meaning                                                                                                              | What happens                                                           |
| ----------------- | -------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Equivalent        | The changed code behaves the same for every input the function can receive                                           | Recorded with a one-line proof. No test                                |
| Not worth killing | Behaviour nobody relies on: log text, an unreachable guard, display copy whose only test would pin the exact wording | Recorded with a reason. The reviewer checks the reason                 |
| Tax gate          | Only a test that asserts a UK tax figure could catch it                                                              | Logged, not tested, until the owner's tax vector sign-off (decision 8) |
| Possible bug      | Hand working disagrees with what the code returns                                                                    | Reported to the coordinator. Engine source is not changed in M2        |

A real gap gets a test and no row here. Several faults on one source line with the same class and reason share a row. Line numbers are those of the source on the date given in each section; they drift as the code changes, so match on the fault and the source text as well.
