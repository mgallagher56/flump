# Flump pages and features

> **Living documentation**: This inventory covers the routes, pages, and user-facing features currently in `apps/marketing` and `apps/web`. Keep it in step whenever routes or features change.

---

## 1. Domain separation

Flump separates public acquisition and feature education (`apps/marketing`) from the authenticated personal finance app (`apps/web`).

```text
Marketing site (apps/marketing)
├── /                               # Home page, sample picture, rough-figure steps, pay rise tool, FAQ
├── /features                       # Map of the five app areas and the AI connection
├── /features/accounts              # Accounts and net worth feature page
├── /features/budget                # Budget and breathing room feature page
├── /features/pay                   # Take-home pay and Self Assessment feature page (with pay rise tool)
├── /features/savings-and-pension   # Savings, pension and retirement plan feature page
├── /features/debt-and-borrowing    # Debt and borrowing feature page (with debt payoff and mortgage/ISA tools)
├── /features/ai-connection         # Flump MCP overview, 15 tools, example questions, and setup link
├── /preview                        # Interactive sample previews (dashboard, monthly check-in, breathing room)
├── /pricing                        # Beta plan ("Free during the beta") and conditional future plan notice
├── /security                       # Facts on own-figure entry, no payments, AI preview, and disclosure policy
├── /contact                        # Support email for beta invites, questions, feedback, privacy, and complaints
└── /mcp, /tools, /tools/:slug      # 301 redirects to /features/ai-connection, /features, and area pages

Web application (apps/web)
├── /                               # Signed-in: Home dashboard. Signed-out: redirects to marketing site (or /sandbox if ?demo=true)
├── /app                            # Redirects signed-in users to /app/onboarding (if unfinished) or /, signed-out to /login
├── /app/onboarding                 # 4-step setup flow (Income, Housing, Savings, Review)
├── /app/accounts                   # Accounts list (what you own, what you owe, net worth) and monthly check-in sheet
├── /app/accounts/:account          # Single account details, quick balance update, and monthly history
├── /app/accounts/history           # Net worth history across months and monthly check-in sheet
├── /app/budget                     # Budget overview, breathing room, housing cost link, categories, and setup wizard
├── /app/take-home                  # UK take-home pay and pay rise model (always on under Pay)
├── /app/self-assessment            # Self Assessment overview, tax years, records by source, and tax bill estimate (opt-in)
├── /app/self-assessment/:source    # Dedicated source ledger (self-employed, rental, savings, paye)
├── /app/savings                    # Savings balances, ISA allowance used, 12-month interest estimate, and scenario tabs
├── /app/pension                    # Pension pots, workplace and salary sacrifice contributions, and scenario model
├── /app/retirement                 # Retirement plan target, yearly income estimate, counted accounts, and budget lines
├── /app/debt                       # Cards, loans, and overdrafts, avalanche/snowball model, and UK debt tools
├── /app/mortgage                   # Residential and buy-to-let switcher, LTV, alerts, repayment schedule, and scenarios
├── /app/imports, /app/imports/:id  # Review, dry-run preview, commit, and undo for MCP-staged imports
├── /app/invites                    # Beta admin page to create/cancel invite links and manage beta members (404 to others)
├── /app/profile                    # Settings (Profile, Security, Data tabs)
├── /tools, /tools/:slug            # Public signed-out UK calculators with guides and FAQs
├── /login, /signup, /callback, /logout, /invite, /invite/:token, /account-deleted
└── /sandbox, /app/sandbox, /app/forecast, /app/tax, /:feature, /api/*, /account/export, /healthz, /ping, /robots.txt, /csp-report
```

## 4. App-wide behaviour

- **Navigation (`navConfig.ts`, `pageConfig.ts`)**: Single navigation source for desktop header and mobile drawer (`Accounts`, `Budget`, `Pay` -> `Take-home pay` + opt-in `Self Assessment`, `Savings and pension` -> `Savings` + `Pension` + `Retirement plan`, `Debt and borrowing` -> `Cards and loans` + `Mortgage`), plus mobile bottom bar tabs (`Home`, `Accounts`, `Budget`, `Pay`, `More`).
- **Dark and light themes**: Theme switcher in both marketing and web headers.
- **Formatting and numbers**: `tabular-nums` and `en-GB` formatting (`@repo/format`, `useFormatCurrency()`).
- **One home per value (E40)**: Shared figures (net worth, savings balance, ISA allowance used, budget totals, breathing room, debt inputs, tax estimate) come from `loadWorkspacePicture` and `@flump/finance-engine` selectors; when a tax year's rates are not published, surfaces display an explicit refusal notice instead of guessing or carrying forward old figures.
