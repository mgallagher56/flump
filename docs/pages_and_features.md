## 4. Global & App-Wide Features

- **Dark & Light Mode**: Seamless theme toggle available in the main header and mobile drawer.
- **Responsive Navigation**:
  - Desktop: Direct high-frequency links (`Budget`, `Accounts`) + grouped domain dropdowns (`Wealth`, `Planning`) + Profile avatar menu.
  - Mobile: Full-screen mobile navigation drawer (`MobileNavDrawer`) with quick access to all enabled modules, currency indicator, and theme switcher.
- **Multi-Currency Formatting**: Global `useFormatCurrency()` hook ensuring consistent formatting across all tools and calculations.
- **Setup Checklist Persistence**: Financial onboarding milestones are saved directly to `userProfile.setupChecklistCompletedSteps`.

## 5. Mobile Companion Parity (`apps/mobile-companion`)

The Expo / React Native companion app mirrors core web dashboard capabilities for mobile devices:

- **Biometric Authentication**: FaceID / TouchID via `expo-local-authentication`.
- **Mobile Screens**:
  - `DashboardScreen`: Net worth summary, budget status, and quick links.
  - `AccountsScreen` & `AccountDetailScreen`: View balances and recent transaction snapshots.
  - `BudgetScreen`: Category-level spending and cash flow progress.
  - `SavingsScreen` & `ForecastScreen`: Mobile wealth projections.
  - `MortgageScreen`: Amortization and overpayment estimates.
  - `TaxScreen`: Fast mobile receipt image uploads and tax liability previews.
  - `ProfileScreen`: Manage personal settings and mobile security.
