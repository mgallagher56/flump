# Flump: Pages & Features Catalog

> **Living Documentation**: This document is an active, comprehensive inventory of all pages and user-facing features currently usable in the Flump application. Whenever pages or features are added, modified, or removed, this document **must** be updated in tandem.

---

## 1. Clean Domain Separation Architecture

Flump draws a strict boundary between stateless acquisition & education (`flump.co.uk`) and stateful personal data & persistent modelling (`app.flump.co.uk`).

```
flump.co.uk (Marketing / apps/marketing)
├── /                       # Dual-mode Hero Calculator, 4 personas, Compounding teaser, FAQ
├── /tools                  # Public directory of UK financial & debt calculators
├── /tools/:slug            # Standalone programmatic SEO calculators (100% client-side math)
├── /pricing                # Free Manual vs Pro Open Banking & Tax Engine comparison
├── /security               # FCA AISP read-only scope, encryption, GDPR, inquiry modal
└── /guides/:slug           # UK Financial Playbooks with embedded calculator components

app.flump.co.uk (Web Application / apps/web)
├── /                       # Signed-in: dashboard home. Signed-out: redirected to the marketing site (the web app has no public landing page)
├── /sandbox                # Read-only demo for signed-out visitors (three personas; signed-in users are redirected home)
├── /login, /signUp         # WorkOS AuthKit integration
├── /callback               # Session hydration & root cookie onboarding seed reading (no demo or seeded financial data)
├── /logout                 # Session termination & flump_has_session clearance
├── /onboarding             # 60-second baseline setup wizard; every numeric field starts empty (examples are placeholders)
├── /                       # Protected Adaptive Home Dashboard
└── /accounts, /debt, ...   # Core Authenticated Modules (/budget, /pension, /mortgage, /forecast, /tax)
```

## 4. Global & App-Wide Features

- **Dark & Light Mode**: Seamless theme toggle available in the main header and mobile drawer.
- **Responsive Navigation**:
  - Desktop: Direct high-frequency links (`Budget`, `Accounts`) + grouped domain dropdowns (`Wealth`, `Planning`) + Profile avatar menu.
  - Mobile: Full-screen mobile navigation drawer (`MobileNavDrawer`) with quick access to all enabled modules, currency indicator, and theme switcher.
- **Multi-Currency Formatting**: Global `useFormatCurrency()` hook ensuring consistent formatting across all tools and calculations.
- **Setup Checklist Persistence**: Financial onboarding milestones are saved directly to `userProfile.setupChecklistCompletedSteps`.

## 5. Mobile Companion Parity (`apps/mobile-companion`)

The Expo / React Native companion app mirrors core web dashboard capabilities for mobile devices:

- **Biometric Authentication**: FaceID / TouchID via `expo-local-authentication`.
- **Mobile Screens**:
  - `DashboardScreen`: Net worth summary, budget status, and quick links.
  - `AccountsScreen` & `AccountDetailScreen`: View balances and recent transaction snapshots.
  - `BudgetScreen`: Category-level spending and cash flow progress.
  - `SavingsScreen` & `ForecastScreen`: Mobile wealth projections.
  - `MortgageScreen`: Amortisation and overpayment estimates.
  - `TaxScreen`: Fast mobile receipt image uploads and tax liability previews.
  - `ProfileScreen`: Manage personal settings and mobile security.
