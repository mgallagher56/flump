How to read the table:

- Each row is one hand-derived vector from `packages/finance-engine/src/test-vectors/uk-tax.vectors.ts` (182 vectors, 143 verified, 39 unverified). No expected value is computed by the engine.
- Tick `[ ]` to `[x]` once you have checked the expected output against the source URL and the derivation.

- Money is in pounds. Inputs are annual unless stated.
