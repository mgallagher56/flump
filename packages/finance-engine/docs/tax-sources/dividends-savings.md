## Answer to the key question

Dividend ordinary and upper rates DID change from 6 April 2026: ordinary 8.75% to 10.75%, upper 33.75% to 35.75%. Additional stays 39.35%. Dividend allowance stays 500. The repo draft suspicion (10.75 / 35.75 / 39.35) is CONFIRMED for 2026/27. (S3 table; S1 gives the same 2026/27 rates and the 500 allowance.) Neither page contains a prose change note; the change is visible only by comparing table columns.

## Discrepancies vs repo

Repo files: /Users/marcgallagher/personal/flump/.claude/worktrees/e4-tax-engine-48e7e3/packages/finance-engine/src/
Dividend rates are not in tax-rules.ts or uk-tax.ts; they are only in tax-calculator.ts.

1. tax-calculator.ts:659-660 (calculateDividendTax): basicDividendRate 0.0875 and higherDividendRate 0.3375 are hardcoded for ALL tax years. Verified 2026/27: 0.1075 and 0.3575. This is a real bug for 2026/27 (also comment at line 565 lists only 8.75%, 33.75%, 39.35%). Additional 0.3935 (line 661) agrees with verified 2023/24 to 2026/27. Pre-2022/23 rates (7.5/32.5/38.1 MEMORY ONLY) are also not modelled, so 2020/21 and 2021/22 use wrong rates if the engine supports those years.
2. tax-calculator.ts:509-515 dividend allowance: 2023 gives 1,000 (agrees, VERIFIED), else 500 (agrees for 2024/25 to 2026/27, VERIFIED). The startYr <= 2022 branch returning 2,000 cannot be verified from the pages read (MEMORY ONLY says 2,000 was correct for 2020/21 to 2022/23), so no verified disagreement.
3. tax-calculator.ts:499-505 PSA (1,000 / 500 / 0) agrees with S5. uk-tax.ts:18-20 constants (1000/500/0) agree with S5.
4. Starting rate for savings (0%, band 5,000, tapering): no grep match for a starting-rate-for-savings implementation in tax-rules.ts, tax-calculator.ts or uk-tax.ts. Gap rather than a value disagreement; the engine may be over-taxing savings interest for low earners. (grep was keyword-based, not a full read.)
5. tax-calculator.ts:503 higher-band PSA threshold uses a hardcoded 50270 / 50000 test; not a figure covered by this research.
