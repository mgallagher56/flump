# Pension annual allowance and ISA allowance (E25-T1)

Read with WebFetch for E25-T1. WebFetch summarises pages, so values are as reported by that extraction.

- [AA] https://www.gov.uk/tax-on-your-private-pension/annual-allowance. Reported: "This is £60,000 this tax year." The page names no year and covers the current tax year only (2026/27).
- [ISA] https://www.gov.uk/individual-savings-accounts. Reported: "In the 2026 to 2027 tax year, the maximum you can save in ISAs is £20,000".
